1. Game Vision
Overview

Tibia Browser RPG is a browser-based RPG inspired by Tibia, combining active combat progression with idle and offline systems.

Players create characters, defeat monsters, collect loot, improve equipment, participate in a player-driven economy, and compete in seasonal ladders.

The game is designed around:

Long-term progression
Meaningful risk versus reward
Item hunting
Economy management
Character optimization
Seasonal competition

A player's success is determined not only by activity but also by strategic decisions regarding combat, equipment, crafting, gathering, trading, and resource management.

2. Core Gameplay Loop
