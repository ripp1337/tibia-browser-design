# HOLY GRAIL DEFINITION

## Overview

Holy Grail is an account-wide collection system.

Holy Grail tracks discovery of:

- Unique Items
- Set Items

Progress is permanent.

Progress remains even if:

- Item is sold
- Item is destroyed
- Item is salvaged
- Item is lost
- Character is deleted

Holy Grail progression never resets.

---

# Account-Wide Rules

Holy Grail is account-wide.

Holy Grail Progress is shared across:

- Characters
- Seasons

Holy Grail is one of the few systems that is not character-based.

---

# Registration Rules

Every time a player finds:

- Unique Item
- Set Item

the item is permanently registered.

The registration remains even if the item is:

- Sold
- Salvaged
- Destroyed
- Lost

Progress is permanent.

---

Players can view Holy Grail progress at any time.

# Account Progression

The following systems are Account-Wide:

- Achievements
- Achievement Score
- Holy Grail Progress

Everything else remains Character-Based.

---

# Unique Collection

The Holy Grail permanently tracks discovered Unique Items.

Progress is based on discovery.

Ownership is not required after registration.

---

# Set Collection

The Holy Grail permanently tracks discovered Set Items.

Progress is based on discovery.

Ownership is not required after registration.

---

# Set Progress

Holy Grail tracks Set completion progress.

Examples:

Rat Set:

2 / 4

Vampire Set:

3 / 5

---

## Set Collection Achievements

Every completed set grants:

- Achievement
- Achievement Points

Examples:

Complete:

- Vampire Set
- Rat Set
- Dragon Set

Ownership is not required permanently.

Once all pieces have been found at least once, the achievement is granted.

---

# Ultimate Achievement

Holy Grail Completion

Requirement:

Discover every Unique Item and Set Item in the game.

Progress is tracked permanently.

This represents full completion of the collection system.

The Holy Grail is intended to be one of the most difficult and prestigious objectives in the game.

---

# Seasonal Rules

Holy Grail Progress is Account-Wide.

Seasonal resets do not affect Holy Grail progress.

Progress remains forever regardless of:

- Character
- Season
- Item Loss
- Trading
- Salvaging

Examples:

Holy Grail:

45%

Holy Grail:

82%

Holy Grail:

100%

Progress never resets.

---

# Non-Ladder Rules

Account-wide systems are unaffected by seasonal transfers because they already belong to the Account.

Included systems:

- Achievements
- Achievement Score
- Holy Grail Progress
- Outfit Collection
- Addon Collection

These systems remain permanently available across all seasons and characters.
